# Contributing

This is an independent research portfolio. Contributions should improve evidence quality, analytical clarity, or reproducibility.

1. Add a source to `research/sources.md` with title, publisher, publication date (if available), URL, access date, and the exact claim it supports.
2. Label statements as fact, inference, hypothesis, recommendation, or illustrative assumption.
3. Do not add fabricated customer quotes, internal metrics, or claims about proprietary systems.
4. Validate calculations and document formulas and units.
5. Keep synthetic data clearly labelled and never commit personal or confidential data.
6. Update relevant Markdown, CSV, and Mermaid files together.
7. Run `python analysis/unit_economics.py` and `python analysis/funnel_analysis.py` before submitting changes.
8. Use a concise pull-request description with the reason for the change and any limitations.
