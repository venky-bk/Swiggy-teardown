# 13 — Strategic trade-offs

| Trade-off | Risk | Counter-metric / guardrail |
|---|---|---|
| Speed vs safety | Pressure to deliver faster may create unsafe incentives | Safety incidents, speed-related complaints; never incentivise unsafe driving |
| Conversion vs transparency | Hiding fees can increase short-term checkout but damage trust | Price-surprise complaints, cancellation after fee reveal |
| Personalisation vs privacy | More behavioural data may improve ranking but over-collect | Consent, data minimisation, opt-out and deletion completion |
| Discounts vs sustainable economics | Promotion-led orders may be non-incremental | Contribution/order, incremental lift, post-promo retention |
| Ads vs relevance | Paid placements can crowd out useful discovery | Search success, relevance feedback, labelled-ad comprehension |
| Automation vs human support | Automated recovery can fail complex cases | Repeat contacts, unresolved cases, escalation time |
| Breadth vs simplicity | More verticals/features can raise navigation cost | Time-to-first-relevant-choice, task success |
| ETA precision vs honest uncertainty | A precise but unreliable ETA damages trust | ETA calibration, error distribution, confidence interval coverage |
| AI convenience vs transaction control | Agent may select wrong item, address, or coupon | Explicit confirmation, reversals, unauthorised-action rate |
| Dietary discovery vs safety claims | Incomplete restaurant data can mislead users | Data provenance, correction rate, allergen incident response |

## Principle
Optimise for durable fulfilled value, not one isolated funnel metric. Any change should be evaluated across consumers, restaurants, delivery partners, and contribution economics.
