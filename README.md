# Swiggy Product Teardown

A portfolio-ready product management teardown of Swiggy, with a focus on AI, emerging technology, product strategy, metrics, and experimentation.

## Project contents

- Product and company overview, scope, personas, JTBD, and user journey
- UX audit, competitor analysis, positioning, market opportunity, and business model
- Unit economics, KPI tree, funnel and cohort analysis
- AI/technology assessment, opportunity backlog, prioritization, and proposed solution
- Product requirements document (PRD), technical design, experiments, roadmap, risks, and executive recommendation
- Event tracking plan, risk register, diagrams, and Python analysis examples

## Repository status

This repository is being populated with the complete teardown project. See the `docs/`, `analysis/`, `data/`, `diagrams/`, `research/`, and `presentation/` directories for the detailed project artifacts.

## Important note

This is an independent product analysis, not an official Swiggy document. Any estimates or hypotheses should be validated against current company disclosures and real user research before being treated as fact.
